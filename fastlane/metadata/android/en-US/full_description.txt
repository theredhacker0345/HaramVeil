HaramVeil is an on-device Android content filter built for Muslims who want practical help lowering the gaze.

It uses three local detection layers:

- Mode 1 scans the visible app UI tree for risky text, IDs, and monitored packages.
- Mode 2 captures limited screen regions and runs OCR using a fully open-source ONNX OCR engine (RapidOCR).
- Mode 3 runs NudeNet ONNX inference on the same cropped regions for visual explicit-content detection.

When HaramVeil blocks content, it shows a native veil overlay, sends the user to the launcher, and places the app into lockdown for the configured duration.

Key points:

- No cloud detection — all processing happens on-device
- No tracking — no analytics, no telemetry, no data leaves your phone
- No internet permission in release builds
- Local encrypted history (SQLCipher)
- PIN-protected settings with security questions
- Device Admin and reboot recovery
- GPL-3.0 licensed

The F-Droid build uses the fossOnnx flavor, which includes only open-source dependencies (ONNX Runtime, RapidOCR, AndroidX, Coil, SQLCipher). No proprietary libraries such as Google Play Services or ML Kit are included.

All detection models (NudeNet ONNX weights and RapidOCR) are bundled in the APK or loaded from local storage — no network downloads required.
